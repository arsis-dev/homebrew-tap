# arsis-dev/tap

Homebrew casks for apps by [arsis-dev](https://github.com/arsis-dev).

```sh
brew install --cask arsis-dev/tap/appotheque
```

| Cask | App |
|---|---|
| `appotheque` | [Appothèque](https://github.com/arsis-dev/appotheque): menu bar launcher for the Mac and iOS apps you are building |
